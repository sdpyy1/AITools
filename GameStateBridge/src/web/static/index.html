配置说明

死亡浏览器

当你在游戏中死亡时，自动打开指定网页；复活后暂停并最小化浏览器

会用本机 Google Chrome 打开；复活后会先暂停播放，再最小化浏览器。

使用说明

  • 激活 CS2 适配器后，程序会自动检测你的生死状态
  • 建议填写 SteamID64，程序会优先按 SteamID 匹配你本人，避免观战队友时误判
  • 死亡时会打开 Google Chrome 访问配置的网页
  • 复活时会先发送一次空格暂停播放，然后最小化 Chrome
  • 其它配置会自动保存到本地，下次启动时恢复
